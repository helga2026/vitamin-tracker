# Умный трекер витаминов и здоровья (MVP)

Mobile-first веб-приложение, выглядящее как нативное мобильное приложение.
Имитация бэкенда — LocalStorage (данные переживают обновление страницы).

## Экраны

| Роут | Описание |
|---|---|
| `/onboarding` | Приветствие + имя/email (флаг сохраняется в LocalStorage) |
| `/` | Главная: приветствие, витамины с чекбоксами, круговой прогресс «Выполнено на X%», кнопка «Пройти опрос здоровья» |
| `/survey` | Пошаговый опрос (6 вопросов) → экран «Базовый отчёт» с рекомендацией, флаг `surveyCompleted` |
| `/uploads` | «Мои анализы»: кнопка загрузки PDF + drag-and-drop, список файлов в LocalStorage |
| `/profile` | ФИО, пол, возраст, цели; кнопка «Перейти на сайт партнёра» (window.open) |

Нижний таб-бар: **Главная · Опрос · Анализы · Профиль** (скрыт на онбординге).

## Стек

React 18 (UMD + Babel) · Tailwind CSS (CDN) · Lucide Icons — без сборки, один файл.
Лёгкий hash-роутер вместо React Router DOM (работает без сборщика, поведение идентично).

## Дизайн-система

- Фон `#F9FAFB`, акцент `#10B981` / `#0D9488`, текст `#1F2937`
- `rounded-2xl/3xl`, `shadow-sm`, много воздуха, плавные переходы (0.3s+)
- Mobile-shell: `max-w-md mx-auto`, `h-screen`, `overflow-hidden`

## Запуск

Открыть `index.html` в браузере (F12 → эмуляция телефона для проверки Mobile-First).

## Проверка (по чек-листу промпта)

1. Отметить витамин → обновить страницу → галочка остаётся
2. Пройти опрос → отчёт появляется, после F5 остаётся
3. Загрузить PDF → файл в списке, после F5 остаётся
4. Изменить профиль → сохраняется

> Приложение не ставит диагнозов и не назначает препараты — только удобный учёт.
